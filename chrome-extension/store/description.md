# Chrome Web Store listing copy

## Name

Genjutsu AI

## Short description (≤132 characters)

Upload images or videos, then open Genjutsu AI to create motion-transfer and object-swap clips.

## Detailed description

Genjutsu AI is a companion for genjutsuai.net.

Use this extension to:

- Select images or videos (local preview only)
- Draft a prompt for your next generation
- Open Genjutsu AI in one click to create motion-transfer and object-swap videos on the website

This version does not generate videos inside Chrome. Clicking Generate opens https://genjutsuai.net. Your selected files stay on your device and are not uploaded by the extension.

Website: https://genjutsuai.net
Support: support@genjutsuai.net
